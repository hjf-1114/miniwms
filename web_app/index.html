MiniWMS 货主 物料 库位 收货 出库 库存

欢迎使用 MiniWMS

轻量多货主 WMS（Flask + SQLite）。本页为前后端一体的本地 demo： 通过上方导航管理货主 → 物料 → 库位三类主数据， 完成收货上架与拣货发货的完整出入库流程， 并在库存页查询余额、流水与账实核对。 后续里程碑将逐步提供移库与盘点等操作页面。

服务地址：http://localhost:5100 · 启动方式：python main.py · API 文档见仓库 README.md
