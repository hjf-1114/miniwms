欢迎使用 MiniWMS

轻量多货主 WMS（Flask + SQLite）。本页为前后端一体的本地 demo： 通过左侧导航管理货主 → 物料 → 库位 → 客户四类主数据， 完成收货上架、拣货发货与库位间移库的完整出入库流程（出库单关联客户、移库单单据驱动原子转移）， 并在库存页查询余额、流水与账实核对。系统管理下已提供角色 / 用户与登录鉴权。 已完成主数据深化（产品/货主/客户/库位字段增强 + 承运商模块）、出入库作业（收货上架 / 拣货发货 / 库位间移库 / 账实盘点）与 批次追溯（验收入库生成唯一批次号、关键批次信息档案），后续将逐步提供预警、报表、外部对接与 CSV 等操作与分析能力。

服务地址：http://localhost:5100 · 启动方式：python main.py · API 文档见仓库 README.md
