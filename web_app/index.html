MiniWMS 货主 物料 库位

欢迎使用 MiniWMS

轻量多货主 WMS（Flask + SQLite）。本页为前后端一体的本地 demo： 通过上方导航管理货主 → 物料 → 库位三类主数据， 后续里程碑将逐步提供收货上架、拣货发货、库存流水、移库与盘点等操作页面。

服务地址：http://localhost:5100 · 启动方式：python main.py · API 文档见仓库 README.md
