## 6. 打印方案（v2 定稿 · 演示版零安装路线）

### 6.1 定稿口径（2026-11-05 用户第二轮答复）

| # | 议题 | 定稿 |
|---|---|---|
| 1 | 自动打印验收标准 | **自动弹出已生成 PDF 的打印预览、人工点确认即可（零安装）**。因为本项目是演示版，先不考虑静默无人值守 |
| 2 | PDF 生成 | **不额外安装就能实现的方式** → 用系统 Chrome headless `--print-to-pdf --no-pdf-header-footer`，零新增 Python 依赖 |
| 3 | 「内容可编辑」 | 打印时能看到打印内容，且**可临时微调单据内容**（数量 / 备注 / 收货人等）；指**打印件内容**，不是模板源码 |
| 4 | 模板编辑器 | **占位符 + 字段映射 与 可视化拖拽排版 都实现**，分两层交付（见 6.4） |
| 5 | 自动触发节点 | **先不考虑**，等全部做好后由用户额外补充；M42 编号保留但**暂不排期** |

### 6.2 技术约束与关键事实（不变）

- 项目硬约束：**唯一 Python 依赖 Flask**，`web_app/` 零依赖原生 HTML/JS/CSS。
- 浏览器里的 `window.print()` **必然弹出系统打印对话框**，无法静默；真正的「自动打印」
  必须借助本机打印代理。v2 明确接受「自动弹预览 + 人工确认」，因此**不引入任何本机代理**。
- 本机已装真实 Chrome（E2E 一直用 `channel="chrome"`），因此 Chrome headless 出 PDF 可直接用。
- 未来若升级为真静默：QZ Tray（WebSocket，PDF/ZPL/ESC-POS）可作**可选适配层**插入，
  模板层与 PDF 生成层不用改；但其静默需证书签名、且每台机器只能跑一个实例，演示版不引入。
- 纯 Python 库（ReportLab / WeasyPrint）**不采用**：破坏「唯一依赖」，且不解决打印环节。

### 6.3 数据模型与生成链路（M41）

- `print_template`：`id / node / code / name / version / is_active / layout_json / field_map / note`；
  `node` 取值如 `receive / putaway / pick / check / ship / label`，一个节点可挂多模板、一个生效。
- **渲染链路**：单据数据 → 套用 `layout_json` + `field_map` 生成纯 HTML（内联 CSS，不依赖外网资源）
  → 后端 `subprocess` 调系统 Chrome headless 出 PDF 到临时目录 → 前端 `<iframe>` 预览 PDF
  → 点「打印」调用 `window.print()`（或 iframe 的打印）弹出系统对话框 → 人工确认出纸。
- **PDF 本身不可编辑**，所以「内容可微调」在 **HTML 编辑层**完成：预览页左右分栏，
  左侧是镜像模板字段的**可编辑表单**（数量 / 备注 / 收货人等可改字段），右侧是 PDF 预览；
  改字段后重新生成 PDF 并刷新 iframe。
- **「临时改」口径**：微调只作用于**本次打印件**，**不回写业务单据**（库存/单据数据不变），
  避免「为了改打印备注而改动已审核单据」；如需留痕可另存打印快照（可选，细节层再定）。

### 6.4 模板编辑器两层实现（都做，共用一份 JSON schema）

| 层 | 能力 | 零依赖实现 | 交付顺序 |
|---|---|---|---|
| L1 占位符 + 字段映射 | 文本/HTML 片段里插入 `{{field}}` 占位符；下拉选字段、显隐、标题与列宽配置 | `contenteditable` + 字段下拉插入 + 表单配置 | 先做，保证「能配就能打」 |
| L2 可视化拖拽排版 | 拖拽区块（表头 / 明细表 / 合计 / 签核栏）排序、字段拖入区块、区块增删 | 原生 HTML5 `drag & drop` + CSS Grid；`layout_json` 存区块顺序与字段绑定 | 后做，作为增强 |

- 两层共用同一份 `layout_json`（区块数组 + 每区块字段绑定），L1 是 L2 的可读文本视图，
  L2 是同一份数据的可视化视图，**不会推倒重来**。
- 演示版推荐做**区块级拖拽排序 + 字段显隐/列宽**，不做像素级自由定位：
  区块拖拽可控、打印分页稳定、零依赖；像素级自由定位对 A4 分页与中文换行极易出问题。
  （若后续确需像素级，再作为细节层扩展。）

### 6.5 M42 后置说明
